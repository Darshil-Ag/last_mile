Input: Pickup & drop address, package dimensions (L×B×H), actual weight, order type (B2B/B2C), payment type (Prepaid/COD) • Output: Order with auto-calculated charge, agent assignment, status tracking, notifications • Admin manages zones, assigns areas to zones, and configures rate cards (intra and inter-zone rates separately for B2B and B2C) and COD surcharge per order type • Customer can register, log in, and place an order; Admin can also create orders on behalf of a customer • On order creation, system detects pickup and drop zones, calculates volumetric weight (L×B×H ÷ 5000), bills on higher of actual vs volumetric weight, applies zone rate from correct rate card (B2B or B2C), and adds COD surcharge if applicable. The charge is shown before the customer confirms • Admin can manually assign a delivery agent to an order or trigger auto-assignment to the nearest available agent • Delivery agent updates order status (Picked Up / In Transit / Out for Delivery / Delivered / Failed) • On failed delivery, customer receives notification and can reschedule for a new date; agent is reassigned for the rescheduled attempt • Customer can view live order status and full tracking timeline • Email notifications sent to customer on every status change • Admin can view all orders, filter by status/zone/agent, and override any order status
